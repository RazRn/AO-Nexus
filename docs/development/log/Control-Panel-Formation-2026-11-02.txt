Control Panel formation experiment — 2026-11-02

Scope
Follow, Gather and Stop beside the Team heading, behind ExperimentalTeamAutomation.
Leader and spacing persist; active movement does not. Spread is deferred.
All participants must be local clients in the same team, area and SyncManager channel.
The supported adapter is AOSP ManagerSync.ManagerSync in the selected 64-plugin installation.

Movement ownership
The AOSP OnMoveMessage receiver ignores the SyncMove checkbox. The temporary lease
therefore disables movement sending AND removes only that exact movement receiver.
Attack, target and guard callbacks remain attached. Stop restores the old movement
setting and receiver. No transient setting is saved to the plugin's configuration.
Game API calls and callback changes run on the game update thread.

Follow records the leader's route and uses ordinary movement towards breadcrumb
positions. It does not teleport or plan routes around obstacles. It stops on blocked
line of sight, no progress, excessive distance/height, stale leader state, changes
to the team/channel, manual follower input, zoning/death, or expired Nexus contact.
Zoning requires an explicit fresh Start. Closing the Control Panel stops the session.

Implementation findings
- The first live Gather encountered an IOException during shared snapshot exchange.
  A per-path named mutex now serializes background reads/writes across the six clients.
  A FileShare.Delete-only experiment did not reliably avoid a missing-path interval
  during File.Replace; it was reverted. The mailbox has a six-reader stress regression.
- A fresh roster is read through the existing exported team-list API and AO# TeamMember
  decoder because the managed Team.IsInTeam query can be false after zoning. No new
  team-member memory offsets were introduced. Post-zone live validation remains pending.
- WinForms focus restoration could scroll the Team header out of view. The sections
  container now preserves its scroll position when a child receives focus.

Validation

  route interpolation and request validation).

  suspended and SyncManager still enabled.

  not captured, so this does not prove every turn was smooth.
- Attack callback preservation was tested in the adapter fixture, not in live combat.
- Zoning and five-second lost-Nexus watchdog are implemented but not yet live-tested.
