31 OCTOBER OPTIONAL-COMPONENT PREVIEW
The bundled-install instructions below describe the older private build.
Default builds now download only the renderer on demand; a matching Rebirth
patch must be supplied separately. See Optional-Components.txt for the current
packaging, licensing constraints and validation status.

USE
Close AO clients using the chosen folder. Open Settings > Graphics, select the
account's game folder (or Choose another game folder), check Use AO-VK and Save.
The first Save installs the bundled renderer and saves the original files.
No prepared test folder, marker file or prior AO-VK installation is required.
Clear Use AO-VK and Save to restore the exact original renderer and, for Rebirth,
its matching original patch. Graphics preferences remain available for next time.
Cancel writes nothing. All accounts using a folder share its graphics settings.
Choosing a graphics folder does not change any account's game folder or server.
Start the game through Nexus; the game's own patcher can restore its own files.

SUPPORTED FILE SETS ON THIS PC
- D:\Games\AORebirth-Live: known classic Rebirth client and version.dll pair.
- D:\SteamLibrary\steamapps\common\Anarchy Online: known classic official client.
- D:\Games\Project Rubi-ka: known classic PRK client.
- The existing D:\Games\AORebirth-AOVK-Test remains supported.
Detection uses file hashes, not the folder name or selected server. These file
sets can therefore be used in another ordinary folder without preconfiguration.
Unknown/mixed client builds, unknown version.dll patches and New Engine are
blocked. In particular, AORebirth-Local has a different version.dll and needs
its own compatible patch build; this version does not replace it.
This feature does not convert one server's client into another server's client.

FILES AND RECOVERY
The original renderer is retained as randy31_orig.dll. Rebirth also retains
version-stock-rebirth.dll. Official AO and PRK receive no version.dll.
Each change also records its previous files and hashes under
NexusGraphicsBackups\<transaction id>\recovery.json. Do not remove backups while
AO-VK is installed. No Funcom renderer binary is bundled in Nexus.
NexusGraphics.lock coordinates graphics changes between launcher instances.
A pending transaction blocks Nexus launch and offers Restore interrupted
graphics change in Settings > Graphics. Recovery checks hashes and preserves
unrelated edits. Torn files or altered recovery records can require manual
restoration from NexusGraphicsBackups; do not delete the pending marker before
restoring the complete recorded file set. A normal write failure rolls back.
