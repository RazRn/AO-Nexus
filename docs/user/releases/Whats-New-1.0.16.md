# AO Nexus v1.0.16

- Update saved password now asks once for your existing game-account password. The confirmation field is removed.
- Clearer English and Danish help explains that Nexus saves a local copy; it does not set or change the password on the game server.
- The password dialog is more compact. Masking, encrypted storage, per-account remembering and cancellation behavior are preserved.
- All seven README screenshots have been regenerated from this version, including the current layout, preset shortcuts and password dialogs.

No experimental same-account parallel-login changes are included.
