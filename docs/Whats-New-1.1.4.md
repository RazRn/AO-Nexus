# AO Nexus v1.1.4 — Clear activity log

The activity-log window now has **Clear log…**. Confirmation defaults to Cancel. Confirming clears the entire session history, including entries hidden by a search, resets the filter and updates the main-window preview. New activity continues to appear normally.

The activity log is stored in memory, so this does not delete a disk file. The separate persistent update-history file remains unchanged. Clearing is not reversible.

Verified cancellation, filtered clearing, both log views, byte-count reset, reopening and new entries with synthetic data. Guide screenshots are refreshed. All [v1.1.2 features](Whats-New-1.1.2.md) and the [resize fix](Whats-New-1.1.3.md) remain included; Game GUI is experimental.
