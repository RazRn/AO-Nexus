# AO Nexus v1.0.18

- **Team presets:** a compact picker with Save new, Edit and Delete. Names and optional start/logout shortcuts live in the create/edit dialog. Save applies changes together; Cancel discards them. Replacing a team's characters is an explicit checkbox in Edit.
- **Terminal-style activity log:** dark background, readable green monospace text, and no redundant status heading. Open log opens a larger, resizable window with live updates, case-insensitive text search, Clear search, Ctrl+F and Follow new entries.
- **Tidier news:** dates appear beside the server name, aligned right. Headlines wrap, with a smaller gap before the article text and content-sized cards.
- **GitHub updates:** check for stable releases in Settings, optionally check once when Nexus starts, and choose Install and restart. The downloaded ZIP and executable are verified before replacement. Installation waits for Nexus to close, keeps the previous EXE as a backup, then reopens Nexus.
- **Updated guide:** all eleven screenshots are regenerated from this build, with image URLs updated when their content changes.
- **Smaller header:** the extra tagline is removed; attribution stays below the title and the account list gains the space.

Saved accounts, passwords, team membership and shortcuts are preserved. The updater is available starting with this version; older installs need one manual update. The first launch asks whether to enable startup checks; the choice is remembered and can be changed in Settings. Updates never install silently. Finish or stop launcher activity before installing; existing games can remain open. Experimental same-account parallel login remains excluded.
