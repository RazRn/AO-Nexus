# AO Nexus v1.0.17

- Saved setups are now called **Teams** throughout the interface and guide.
- **Expand all** and **Collapse all** are compact text links beside the Accounts by server heading.
- Add account, Add character, Edit, Remove, Select all and Clear selection are grouped inside Accounts by server, directly above the list. The toolbar wraps at narrower window sizes.
- Guide screenshots have been refreshed for the new layout.

Saved accounts, team selections and shortcuts are preserved. Experimental same-account parallel login remains excluded.
