WHAT'S NEW IN 1.2.2

• Reports clearly state when no responsiveness measurements are available. Missing, unreadable, invalid and mismatched monitoring snapshots have separate explanations.
• Session summaries retain earlier memory peaks, update gaps, reply times and state counts alongside the latest 120 samples. They cover only the time Nexus observed the client.
• Client aliases match throughout each diagnostic ZIP. Duplicate saved exits are omitted; distinct evidence is kept.
• Reports show the installed Windows version and build instead of the legacy compatibility version.
• The player guide and monitoring help explain how to enable measurements and interpret reports.

Start with report-summary.txt. Process samples and exit code zero do not prove the game was responsive or rule out a crash. Monitoring remains optional and must be enabled for each character through AOSharp. Existing v1.2.1 monitoring plugins remain compatible. Nothing is uploaded automatically.
